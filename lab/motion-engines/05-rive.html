@rive-app/canvas 2.21.6 · 219 KB runtime + 1.2 MB of WebAssembly — by far the heaviest of the five. Rive's good idea is the State Machine: a designer authors states and transitions rather than a linear clip, and the developer only supplies inputs. Two costs — (1) the size above, and (2) a .riv is a binary produced only by the editor, so it cannot be written into this repository by hand. When the file is missing this page says so.
