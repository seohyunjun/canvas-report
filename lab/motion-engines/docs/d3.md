## Minimum usage
```html
<script src="vendor/d3-7.9.0.min.js"></script>
<script>
  var x = d3.scaleLinear().domain([0, d3.max(data, d => d.v)]).range([0, 420]);

  // The key is the whole argument. Without it the join falls back to array index.
  var sel = svg.selectAll('g.bar').data(data, d => d.k);

  sel.exit().transition().duration(450).style('opacity', 0).remove();
  var ent = sel.enter().append('g').attr('class', 'bar');

  ent.merge(sel).transition().duration(800).ease(d3.easeCubicOut)
     .attr('transform', (d, i) => `translate(0,${i * 44})`);
</script>
```

## What only this tool does
**Object constancy.** D3 does not animate elements you hand it; it animates *the relationship
between data and elements*. Give the join a key and a reorder becomes **movement** — each bar
travels to its new row and the eye follows one series through the change. Drop the key and the same
transition describes nothing: bars stay put while their labels and lengths swap underneath.

The lab page has that as a checkbox so you can watch the difference. It is measurable, not a
matter of taste — with the key on, reordering leaves DOM order untouched and changes only the
`transform`; with it off, DOM order changes and nothing moves.

`enter` and `exit` are the same idea extended to elements that must appear and disappear. Neither
the canvas-report shell nor any motion engine in this lab has an equivalent: the shell repaints a
canvas from scratch every frame, so there is no element whose identity could be kept.

## What this skill takes / refuses
- **Takes:** the form catalogue and the scale/shape maths, reimplemented on canvas
  (`references/external-tools.md` § The D3 gallery, mapped onto this skill).
- **Refuses:** the 280 KB, and the DOM ownership. A report is a document that is read once and
  archived; object constancy has nothing to be constant *through*.

## Two traps, both hit while verifying this page
- **`.interrupt()` cancels a transition without running its `.remove()`.** An interrupted exit
  leaves the element in the DOM permanently. If you interrupt, remove the exit set yourself.
- **`.duration(0)` is still a transition.** It needs a frame to apply. Under
  `prefers-reduced-motion`, or when rAF has stopped, a zero-duration transition lands *nothing*.
  Branch on the duration and write the attributes directly when it is zero — the lab page does.

Both are the D3 shape of the lab's general finding: no engine here guarantees a final state.

## When to reach for it
When the deliverable is an **application** whose data changes under the reader — a live dashboard,
a filterable explorer, anything where the same entity must stay recognisable across updates.
Not for a document.

## Motion decision

Use `spatial-reordering` only when a keyed join makes rank movement analytically meaningful.
Otherwise keep the chart static; a filter is not a re-sort and the static fallback must retain all
rows and labels.
